# Dungeon Crawler

A small 2D pixel-art dungeon crawler being built with **Godot 4** and **GDScript**.

This project is both a game and a learning project. I'm a beginner programmer and game developer using this project to learn more about programming, game development, Godot, and how a larger project comes together.

Rather than waiting until I know everything before building something, I'm learning by doing — adding features, breaking things, debugging them, and improving the project as I learn.

## 🎮 About the Game

Dungeon Crawler is inspired by classic top-down dungeon games.

The goal is to keep the game relatively small while building out systems such as:

* Player movement and animation
* Melee combat
* Enemies and damage
* Chests and item pickups
* Doors and room interactions
* Inventory and items
* Dungeon exploration
* Puzzles
* Additional enemies and combat mechanics

The project is still **very early in development**, so expect things to change frequently.

## 🛠️ Built With

* **Godot 4**
* **GDScript**
* **Aseprite**
* Pixel-art assets

## ▶️ Running the Project

To run the project locally:

1. Install **Godot 4**.
2. Clone or download this repository.
3. Open Godot.
4. Select **Import**.
5. Navigate to the repository folder.
6. Select `project.godot`.
7. Open the project and run it.

Using Git:

```bash
git clone https://github.com/derrickguerrerovelasquez-spec/Dungeon-Crawler.git
```

Then open the cloned folder through Godot.
